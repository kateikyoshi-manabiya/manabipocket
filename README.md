# まなびポケット

小学生から高校生までを対象にした、学年別の問題と学習記録を試せる学習アプリのMVPです。

## 起動方法

`index.html` をブラウザで開くと使えます。ビルドや依存パッケージは不要です。

## できること

- 小学1年生から高校3年生までの学年を選択
- 学年と教科を選び、複数の単元と問題数を設定して問題に挑戦
- 小学6年生の算数は、学習指導要領の領域をもとに整理した8単元から、計算・考え方・文章題を組み合わせて出題
- 小学6年生の算数で標準問題と応用・適性検査対策の問題を切り替え
- 中学3年生の英語で標準・応用・受験のレベルを選び、レベル別の文法・語彙・会話・読解問題に挑戦
- サイドメニューに、家庭教師まなびやの「できた！」を一つずつ積み上げる考え方を取り入れた日替わりメッセージを表示
- デスクトップのサイドメニュー、スマートフォンのホーム画面、問題画面から、詳しい解説や学習相談を希望する人向けに家庭教師まなびやの案内を表示
- 正誤と解説の確認、挑戦回数・正解数・学習日数の記録
- 問題に回答するたびに学習記録を保存し、「学習のきろく」画面で過去50回分の教科・単元・学年・回答数・正解数と、間違えた問題の解答・解説を確認（復習問題は新しい順に最大100問）
- スマートフォンとデスクトップに対応した画面

小学6年生の算数は標準問題と応用問題を切り替えられます。標準問題は、学習指導要領の領域をもとに整理した8単元から計算・考え方・文章題を出題し、学習ごとに数値を変えます。小数の答えは小数第2位を四捨五入して小数第1位まで求める形式です。各単元の直近200問と同じ問題を避け、出題履歴はこのブラウザに保存します。割合・百分率では、もとにする量や比べられる量、値引き・値上がりなどを練習できます。学習指導要領解説の「数と計算」「図形」「変化と関係」「データの活用」を軸にしています。速さ・単位量あたりは関連する既習内容の活用問題です。その他の学年・教科はサンプル問題です。

小学6年生の算数の「応用・適性検査対策」には、分数、割合、比、速さ、図形、縮尺、データ、文字式、場合の数・条件整理の各単元に50問ずつ、合計450問を出題します。複数の問題形式を使い、数値や条件を学習ごとにランダムに変えます。小数の答えは小数第2位を四捨五入して小数第1位まで求める形式です。直近200問と同じ問題文は避けます。公開問題の転載ではなく、指定ページの対象領域や「場面を読み取り式を立てる」という学習方針を参考に独自に作成しています（[文章問題Ⅰ](https://happylilac.net/mu1612291631.html)、[文章問題Ⅱ](https://happylilac.net/mu1701251717.html)、[文章問題まとめ](https://happylilac.net/s19_bun_6-ms202601211012.html)）。

小学6年生の算数では「受験対策」を選び、受験先として「山口県」から「県立中学校・中等教育学校（共通検査）」を選択できます。山口県の公開ページに掲載された全40件の検査問題PDF（平成19〜31年度、令和2〜8年度）を参考に、長い場面設定、登場人物の会話や複数資料から条件を読み解く問題、算数・理科の考察、根拠を示した説明・提案などを練習できる41問のオリジナル記述問題を用意しています。問題に合わせて会話文・場面説明・表やグラフを使い分け、複数の情報を結び付けて考える形式です。令和8年度の検査問題を参考にした噴水の問題は12問あり、周期や同時運転のほか、運転時間、水量・流量、節水、実験計画を扱います。問題ごとに必要な文章や資料を読み、計算・比較の道筋と結論を自分の言葉で60字以上にまとめます。回答は自動採点せず、模範例と観点別チェックを使って振り返ります。自己チェックは任意で、省略して次の問題へ進めます。数値や文章は練習用に作成したもので、公開問題の転載ではありません。県の公開ページは県立中学校及び中等教育学校の検査問題を掲載しているため、現在は学校別ではなく共通の受験先として表示しています（[山口県立中学校及び中等教育学校 入学者選抜選考検査問題](https://www.pref.yamaguchi.lg.jp/soshiki/180/26468.html)）。

中学3年生の英語は、標準・応用・受験の3レベルを選べます。各レベルに文法150問、語彙80問、会話10問、読解48問を追加し、初期問題も含めて標準303問、応用302問、受験301問を収録しています。文法・語彙の基礎から、会話の意図や長文中の情報・理由・要旨を読み取る問題まで、単元を選んで学習できます。

単元構成は、文部科学省の小学校学習指導要領解説 算数編の各学年の内容をもとに、このアプリ向けに整理しています。学習指導要領は教科書の章立てを定めるものではないため、教科書会社や学校によって単元名・順序は異なります。

- [文部科学省「小学校学習指導要領（平成29年告示）解説 算数編」](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)
- [文部科学省「学習指導要領等（平成29・30・31年改訂）」](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)

学習記録はブラウザの `localStorage` に保存され、サーバーには送信されません。ブラウザのデータを消去すると記録も消えます。ほかの学年・教科の問題は、今後の拡充対象です。
